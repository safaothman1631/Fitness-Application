🔒 کێشەی گەیشتن بە Firebase

ERR_BLOCKED_BY_CLIENT - چارەسەری تەواو

کێشەکە چییە؟

تۆڕی ئێوە (ISP) یان حکومەت داواکارییەکانی Firebase ڕێگری دەکات.

ئەمە بەهۆی:
• فایەرۆڵی ISP
• ڕێگری حکومەت لە خزمەتگوزارییەکانی Google
• DNS ناشیرین
• ئەنتیڤایرۆس یان فایەرۆڵی ویندۆز

🚀 خێراترین چارەسەر

VPN بەکاربهێنە - ١٠٠٪ کاردەکات!

📥 دابەزاندنی Cloudflare WARP (بێبەرامبەر + خێرا)

1 چارەسەری یەکەم: VPN بەکاربهێنە (پێشنیار دەکرێت)

  • بڕۆ بۆ https://1.1.1.1/ و Cloudflare WARP دابەزێنە (بێبەرامبەرە)
  • یان بڕۆ بۆ https://protonvpn.com/ و Proton VPN دابەزێنە (بێبەرامبەرە)
  • یان بڕۆ بۆ https://windscribe.com/ و Windscribe دابەزێنە (10GB مانگانە بێبەرامبەر)
  • VPN دامەزرێنە و کاری بکە
  • پاش داگیرساندنی VPN، ئەپەکە تاقیبکەرەوە
دابەزاندنی Cloudflare WARP دابەزاندنی Proton VPN

2 چارەسەری دووەم: گۆڕینی DNS بۆ Google DNS

  • PowerShell وەک Admin بکەرەوە
  • ئەم فەرمانانە بنووسە:
netsh interface ipv4 set dns "Wi-Fi" static 8.8.8.8
netsh interface ipv4 add dns "Wi-Fi" 8.8.4.4 index=2
ipconfig /flushdns
  • ئەگەر "Wi-Fi" کاری نەکرد، بینووسە "Ethernet" یان ناوی connection ەکەت
  • کۆمپیوتەرەکە Restart بکە
  • ئەپەکە تاقیبکەرەوە

3 چارەسەری سێیەم: تاقیکردنەوە بە مۆبایل دەیتا

  • WiFi ی کۆمپیوتەرەکە بکوژێنەرەوە
  • مۆبایلەکەت بە Hotspot بکە
  • کۆمپیوتەرەکە بە hotspot ی مۆبایلەکەت بەستنەوە
  • ئەپەکە تاقیبکەرەوە
  • ئەگەر کاری کرد، واتا ISP ەکەت Firebase ڕێگری دەکات

4 چارەسەری چوارەم: لادانی فایەرۆڵی ویندۆز

  • بڕۆ بۆ Settings → Update & Security → Windows Security
  • کلیک لەسەر Firewall & network protection
  • Domain network, Private network, Public network - هەموویان بکوژێنەرەوە
  • ئەپەکە تاقیبکەرەوە
  • ئەگەر کاری کرد، Firebase زیاد بکە بۆ لیستی Allowed apps

⚠️ گرنگ!

ئەگەر هیچیان کاریان نەکرد، ئەوە واتا حکومەت یان ISP ەکەت بە شێوەیەکی بەهێز Firebase ڕێگری دەکات.

تەنها چارەسەر: VPN بەکاربهێنە

پێشنیاری باش: Cloudflare WARP (بێبەرامبەر، خێرا، و ئاسان)
